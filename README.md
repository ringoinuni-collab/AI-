## 商品やサービスの課題
- 現在のPCには、アプリケーションごとに音量を調整できる機能が搭載されている。
- 複数のアプリケーションを同時に使用する場合、利用者自身が音量バランスを調整する必要がある。 例えば、ゲーム中に通話を始めると、ゲーム音によって相手の声が聞き取りにくくなることがある。
- 動画視聴や音楽再生の際にも、音量が大きすぎたり小さすぎたりするたびに手動操作が必要となる。
- 既存の音量調整ソフトウェアや外部コントローラーには、アプリケーション別の音量操作や設定保存に対応した製品が存在する。
- これらはユーザーの表情や過去の操作履歴、現在の利用状況を組み合わせ、個人の好みに応じて音量を学習・調整する機能には、差別化の余地がある。
- 具体的には、以下の課題が考えられる。
  - アプリケーションを切り替えながら音量を調整する手間がかかる。
  - 使用環境が変化するたびに音量を設定し直す必要がある。
  - 個人によって異なる音量の好みに対応しにくい。
  - 不快に感じる音量でも、利用者が自分で操作しなければ改善されない。
  - 複数の音声が同時に流れる場合、聞きたい音を優先する操作が必要になる。

## 自分たちのアプローチ
これらの課題を解決するため、AI、顔画像解析、操作履歴の学習を組み合わせた音量自動調整アプリケーションを開発する。 本システムでは、次の5つの機能を中心に構成する。
### アプリケーション別の音量操作
- PC上で起動しているゲーム、音楽、動画、通話などの音量を個別に管理する。
- スマートフォンやタブレット、外部ダイヤルなどからも音量を操作できるようにし、ゲーム中や作業中でも画面を切り替えずに調整できる仕組みを導入する。
### AIへの自然言語による指示
「通話を聞きやすくして」「ゲームの音を少し下げて」「音楽を小さく流して」など、日常的な言葉によって音量を調整できる機能を搭載する。 AIが利用者の指示を解析し、対象となるアプリケーションと音量の変更内容を判断する。
### カメラによる顔画像解析
- PCに搭載されたWebカメラを使用し、利用者の顔画像から表情や顔の動きを解析する。 例えば、音声再生中に眉をひそめる、目を細める、顔をしかめるなどの反応が確認された場合、音量が適切でない可能性を検出する。
- ただし、表情だけで音量への不快感を断定することは難しいため、直前の音量変化、使用中のアプリケーション、利用者の操作履歴などを組み合わせて判断する。
- AIが音量調整を必要と判断した場合、最初は「音量を下げますか？」と提案する。利用者が承認した調整や、その後の修正内容を学習し、将来的には設定された範囲内で自動調整できるようにする。
- カメラの使用は利用者が選択できるものとし、顔画像は原則として保存せず、PC内で解析処理を行う。
### 過去の操作履歴による学習
- 利用者がどのような状況で音量を変更したのかを記録し、機械学習によって個人の好みを分析する。
- 学習に使用する主な情報は、時間帯、起動中のアプリケーション、通話の有無、音声出力機器、音量の変更履歴などである。例えば、夜間は音量を低く設定する、ゲームと通話を同時に使用するときは通話音声を優先する、ヘッドホン接続時には以前の設定を復元するといった動作を実現する。
- 自動調整後に利用者が音量を変更した場合、その修正を次回の調整に反映することで、利用するほど個人の好みに近づく仕組みを目指す。
### 利用状況に応じた自動調整
- ゲーム、通話、動画視聴などの利用状況を検出し、複数のアプリケーション間で音量バランスを自動調整する。例えば、通話相手が話している間はゲームや音楽の音量を一時的に下げ、会話が終了すると徐々に元の音量へ戻す。
- 「ゲーム＋通話」「オンライン会議」「動画視聴」「作業用BGM」などの利用場面に応じた設定を保存し、自動または手動で切り替えられるようにする。
